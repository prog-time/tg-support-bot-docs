# Начало работы

Это руководство поможет вам развернуть **Telegram Support Bot** с нуля и принять первое обращение от клиента за 15 минут.

## Системные требования

Перед установкой убедитесь, что ваша система соответствует требованиям:

| Компонент | Минимальная версия | Рекомендуемая |
|---|---|---|
| Node.js | 18.x | 20.x LTS |
| npm | 9.x | 10.x |
| PostgreSQL | 14 | 16 |
| SQLite | 3.x | 3.x (только для разработки) |
| ОС | Ubuntu 20.04 / Debian 11 / macOS 12 | Ubuntu 22.04 |
| RAM | 512 МБ | 1 ГБ+ |

> **Совет:** Для локальной разработки и тестирования используйте SQLite — не нужно устанавливать PostgreSQL.

## Получение токена Telegram-бота

Прежде чем начать установку, создайте бота в Telegram:

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Введите имя бота (например, `Служба поддержки MyApp`)
4. Введите username бота (должен заканчиваться на `bot`, например: `myapp_support_bot`)
5. Скопируйте токен вида `1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ`

::: warning Важно
Храните токен бота в секрете. Никогда не публикуйте его в репозитории или логах.
:::

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-org/tg-support-bot.git
cd tg-support-bot
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Создание файла конфигурации

Скопируйте шаблон конфигурации:

```bash
cp .env.example .env
```

Откройте `.env` и укажите обязательные параметры:

```dotenv
# Обязательные параметры
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
BOT_NAME=Служба поддержки

# ID чата администратора (получить через @userinfobot)
ADMIN_CHAT_ID=123456789

# База данных (для разработки используйте SQLite)
DB_TYPE=sqlite
DB_PATH=./data/support.db
```

### 4. Инициализация базы данных

```bash
npm run db:migrate
```

Для заполнения тестовыми данными (опционально):

```bash
npm run db:seed
```

## Первый запуск

Запустите бота в режиме разработки (с автоперезагрузкой):

```bash
npm run dev
```

Или в продакшн-режиме:

```bash
npm run start
```

После успешного запуска вы увидите в консоли:

```
[INFO] Bot started successfully
[INFO] Listening for updates... (polling mode)
[INFO] Admin chat ID: 123456789
[INFO] Database: SQLite (./data/support.db)
```

### Проверка работы

1. Откройте вашего бота в Telegram
2. Отправьте любое сообщение
3. Бот должен ответить приветствием и создать тикет
4. В чат администратора придёт уведомление о новом обращении

## Настройка Webhook (для продакшна)

В продакшн-среде рекомендуется использовать webhook вместо polling для лучшей производительности:

```bash
# Установите публичный URL вашего сервера
WEBHOOK_URL=https://your-domain.com
WEBHOOK_PORT=8443
```

Зарегистрируйте webhook в Telegram:

```bash
npm run webhook:set
```

Проверьте статус webhook:

```bash
npm run webhook:info
```

::: tip Совет
Для быстрого тестирования webhook на локальной машине используйте [ngrok](https://ngrok.com):
```bash
ngrok http 8443
```
:::
