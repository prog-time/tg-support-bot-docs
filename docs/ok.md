# Подключение Одноклассников

Одноклассники — встроенный канал поддержки на базе OK Bot API. Бот принимает
сообщения группы через вебхук и создаёт для каждого диалога отдельную тему
(топик) в Telegram-группе поддержки или обращение в разделе **"Чаты"**, если
группа не настроена. Ответы менеджеров доставляются пользователю обратно в OK.

Эндпоинт вебхука: `POST /api/ok/bot/{secret}`

::: info Предварительные требования
Перед подключением убедитесь, что проект развёрнут по одной из инструкций:

- [Установка через Docker Compose](/docs/installation-on-docker-compose)
- [Установка на хостинг](/docs/installation-on-hosting)

Нужна группа в Одноклассниках, в которой вы администратор.
:::

## 1. Получение токена группы

1. Откройте настройки группы в Одноклассниках.
2. Перейдите в раздел **"Сообщения" -> "Работа с API"**.
3. Нажмите **"Получить ключ доступа"** и скопируйте токен целиком, со всеми
   символами.

::: warning Новый токен отменяет старый
Если перевыпустить ключ в настройках группы, старый перестанет работать. Введите
новый в админ-панели и нажмите **"Сохранить"**: вебхук обновится автоматически.
:::

## 2. Настройка интеграции

1. Перейдите в раздел **"Настройки" -> "Интеграции"**.
2. Нажмите на карточку **"Одноклассники"**.
3. Заполните поля:
   - **Токен группы** — токен из предыдущего шага (хранится в зашифрованном
     виде);
   - **Секретный ключ вебхука** — строка, которая встраивается в URL вебхука
     для проверки входящих запросов (например, `openssl rand -hex 32`). Поле
     обязательно: без ключа все входящие запросы отклоняются.
4. Нажмите **"Сохранить"**. Токен проверяется запросом к OK. Если проверка не
   пройдёт, ничего не сохранится и форма покажет ошибку.

## Проверка

1. Напишите сообщение группе **с другого аккаунта**, который не администрирует
   группу. На сообщения из аккаунта администратора OK не присылает вебхук.
2. В Telegram-группе появится новая тема или обращение в разделе **"Чаты"**.
3. Ответьте из темы или админ-панели. Ответ должен прийти пользователю в OK.

## Какие сообщения поддерживаются

**От пользователя:**

| Тип | Как приходит менеджеру |
|---|---|
| Текст | Текстом |
| Фото, стикер | Изображением |
| Файл, аудио | Файлом |
| Видео | Ссылкой на страницу OK: прямую ссылку на файл OK не отдаёт |
| Контакт, геопозиция, звонок, подарок | Текстовым описанием |
| Ссылка, музыка | Ссылкой |
| Репост из OK без ссылки | Сообщением с ID, смотреть нужно в чате OK |

Если файл не удалось скачать, менеджер получит ссылку на него.

**От менеджера:** текст, фото, документы, голосовые, аудио, видео, кружки,
статичные стикеры и геопозиция. Контакт уходит текстом.

Если файл доставить не удалось, в теме появится предупреждение, а текст
сообщения всё равно уйдёт пользователю.

## Ограничения текущей версии

- Форма оценки текстовая: после закрытия обращения пользователь получает просьбу
  оставить отзыв, без кнопок 1–5.
- Опросы и анимированные стикеры из Telegram не отправляются.
- Голосовые и аудио, которые OK не примет, уйдут обычным файлом.
- Документация OK называет полную и мобильную версии сайта, а поддержку
  сообщений группам в официальных приложениях обещает позже.

## Решение проблем

| Проблема | Что проверить |
|---|---|
| Интеграция подключена, но сообщения не приходят | Сообщила ли форма, что вебхук подписан, и не пишете ли вы из аккаунта администратора группы |
| Токен не принимается | Скопирован ли токен целиком и не был ли он перевыпущен |
| Перестали приходить сообщения | OK может отменить подписку, если сервер не отвечает 8 часов. Откройте настройки интеграции и снова нажмите **"Сохранить"** |
