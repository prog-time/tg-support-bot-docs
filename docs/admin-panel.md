# Admin Panel

Веб-панель `/admin` — основной интерфейс для команды поддержки.

## Доступ

Адрес панели: `https://{ваш домен}/admin`

Для входа нужна учётная запись из таблицы `users`.

Создать нового пользователя через artisan:

```bash
docker exec pet php artisan app:create-admin-user
```

## Разделы панели

### Диалоги

Маршрут: `/admin/chats`

Основной раздел для обработки обращений. Показывает список всех диалогов.

### Интеграции

Маршрут: `/admin/settings/integrations`

Показывает все доступные интеграции. В данном разделе можно подключить интеграции для вашей технической поддержки.

### ИИ-ассистент

Маршрут: `/admin/settings/ai`

Настройки ИИ-ассистента, которые включают:
- подключение и настройка AI-провайдера
- параметры работы AI-ассистента
- поле для ввода системного промпта

### Настройки API

Маршрут: `/admin/settings/api-webhooks`

Управление внешними источниками, интегрированными через REST API.

Создание источника:

1. Нажмите **"Добавить источник"**.
2. При нажатии автоматически создаётся новый источник API.
3. Заполняем поля:
   - **"Название"**, которое будет отображаться в списке API источников
   - **"URL вебхука"**, адрес на который будут отправляться ответы от менеджеров

### Команда

Маршрут: `/admin/settings/team`

Управление операторами и ролями в команде поддержки.

Создание пользователя через панель:

1. Перейдите в «Настройки → Команда».
2. Нажмите «Добавить».
3. Заполните имя, email, пароль (минимум 8 символов) и роль.

Создание через artisan:

```bash
docker exec pet php artisan app:create-admin-user
```
