# Шаблон названия топика

Для каждого нового обращения бот создаёт отдельную тему (топик) в супергруппе
Telegram. Шаблон определяет, как будет называться эта тема — например,
`Иван Петров telegram` вместо безликого номера.

Название формируется один раз, в момент создания топика. Изменение шаблона не
переименовывает уже созданные темы.

## Где настраивается

1. Откройте панель управления → **Настройки → Основные**.
2. В карточке **«Обращения»** заполните поле **«Шаблон названия топика»**.
3. Нажмите **«Сохранить»**.

::: info
Карточка «Обращения» доступна только пользователям с ролью администратора.
Менеджеры видят на этой странице только настройки оповещений.
:::

Ограничение длины шаблона — 255 символов.

## Синтаксис

Шаблон — это обычная строка, в которую подставляются переменные в фигурных
скобках:

```text
{first_name} {last_name} {platform}
```

Результат:

```text
Иван Петров telegram
```

Текст вне скобок остаётся без изменений, поэтому шаблон можно комбинировать с
любыми словами и символами:

```text
Обращение от {first_name} ({username})
```

## Доступные переменные

| Переменная | Описание |
| --- | --- |
| `{id}` | Идентификатор пользователя в мессенджере |
| `{first_name}` | Имя пользователя |
| `{last_name}` | Фамилия пользователя |
| `{username}` | Логин пользователя (без `@`) |
| `{email}` | Email пользователя, если он известен |
| `{platform}` | Канал обращения: `telegram`, `vk`, `max` |

::: warning
Данные пользователя (имя, фамилия, логин) бот запрашивает у Telegram. Если
хотя бы одна переменная из шаблона окажется пустой — например, у пользователя
не задан `username` или скрыта фамилия — название будет собрано по резервному
формату (см. ниже).
:::

## Примеры шаблонов

| Шаблон | Результат |
| --- | --- |
| `{first_name} {last_name} {platform}` | `Иван Петров telegram` |
| `Обращение от {first_name}` | `Обращение от Иван` |
| `#{id} — {first_name} ({platform})` | `#123456789 — Иван (telegram)` |
| `{username} / {platform}` | `ivan_petrov / telegram` |

## Резервное название

Если шаблон не подошёл, бот всё равно создаст топик — но назовёт его по
формату по умолчанию:

```text
#{идентификатор пользователя} ({канал})
```

Например: `#123456789 (telegram)`.

Это происходит в следующих случаях:

- поле шаблона пустое;
- в шаблоне нет ни одной переменной (только текст);
- в шаблоне указана только переменная `{platform}` — добавьте к ней хотя бы
  одну переменную с данными пользователя;
- указано несуществующее имя переменной;
- одна из указанных переменных пуста или недоступна;
- не удалось получить данные пользователя из мессенджера.

::: tip
Чтобы избежать резервных названий, используйте в шаблоне только те переменные,
которые есть у всех пользователей — например `{id}` и `{first_name}`.
Переменные `{last_name}`, `{username}` и `{email}` заполнены не всегда.
:::

## Обращения из внешних источников

Для обращений, пришедших через [внешний API](/docs/admin-panel), шаблон не
применяется. Топик всегда называется по формату:

```text
#{идентификатор пользователя} ({название источника})
```

Название источника берётся из настроек API-источника в разделе
**«Настройки API»**.

## Возможные ошибки

**Тема называется `#123456789 (telegram)` вместо шаблона.**
Сработало резервное название. Проверьте, что поле шаблона заполнено, содержит
хотя бы одну переменную в фигурных скобках и что все использованные переменные
доступны у этого пользователя.

**Изменил шаблон, но названия старых тем не поменялись.**
Так и задумано: название присваивается при создании темы. Новый шаблон
применится к следующим обращениям.

**Опечатка в имени переменной.**
Неизвестная переменная не подставляется, а переводит название на резервный
формат. Имена чувствительны к регистру — записывайте их строго так, как в
таблице выше.
