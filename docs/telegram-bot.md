# Подключение Telegram

Telegram — основной канал поддержки. Бот принимает входящие сообщения
пользователей через вебхук и создаёт для каждого обращения отдельную тему
(топик) в приватной Telegram-группе поддержки. Ответы менеджеров из этой
темы доставляются пользователю обратно в Telegram.

Эндпоинт вебхука: `POST /api/telegram/bot`

::: info Предварительные требования
Перед подключением убедитесь, что проект развёрнут по одной из инструкций:

- [Установка через Docker Compose](/docs/installation-on-docker-compose)
- [Установка на хостинг](/docs/installation-on-hosting)

Для локальной разработки вебхук можно поднять через
[Cloudflare Tunnel (macOS)](/docs/cloudflare-tunnel-webhook-macos).
:::

## 1. Подключение интеграции Telegram

1. Перейдите в раздел **"Настройки" -> "Интеграции"**.
2. Нажмите на карточку **"Telegram"**.
3. Не закрывайте страницу, в следующих пунктах необходимо будет заполнить поля.

## 1. Создание бота в @BotFather

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`.
3. Задайте имя и имя пользователя (username) для бота.
4. Полученный токен вставьте в поле **"Токен бота"**.

## 2. Настройки интеграции Telegram

1. В поле **"Токен"**, вставьте токен, который вы получили при создании бота.
2. В поле **"Секретный ключ Webhook"**, вставьте случайную строку (пароль для защиты интеграции).
