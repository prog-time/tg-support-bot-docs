# Подключение группы VK

Модуль принимает входящие сообщения из группы ВКонтакте через Callback API
и пересылает их в сервис поддержки. Ответы менеджеров доставляются
пользователям обратно в ВКонтакте от имени сообщества.

::: info Предварительные требования
Перед подключением убедитесь, что проект развёрнут по одной из инструкций:

- [Установка через Docker Compose](/docs/installation-on-docker-compose)
- [Установка на хостинг](/docs/installation-on-hosting)
:::

### 1 Подключение интеграции

1. Перейдите в раздел **"Настройки" -> "Интеграции"**.
2. Нажмите на карточку **"ВКонтакте"**.

### 2 Создание ключа доступа

1. Перейдите в **Управление сообществом → Работа с API → Ключи доступа**.
2. Создайте новый ключ с правами:
   - Сообщения сообщества
   - Фотографии
   - Документы
3. После сохранения, полученный токен нужно вставить в поле **"Токен"**, в настройках интеграции.

### 3 Настройка Callback API

Перейдите в **Управление сообществом → Работа с API → Callback API**.

#### 3.1 Вкладка «Серверы»

1. Укажите URL сервера: `https://{ваш домен}/api/vk/bot`
2. Выберите тип: **Callback API**.
3. Укажите версию API: **5.131** или более новую.
4. В поле **Секретный ключ** укажите строку для защиты вашей интеграции. Случайная строка из 10-12 символов.
5. Такой же **Секретный ключ** укажите в соответсвующее поле в настройках интеграции.

#### 3.2 Вкладка «Настройки»

1. Скопируйте **Строку подтверждения** и вставьте её в поле **"Код подтверждения"**, в настройках интеграции.

#### 3.3 Вкладка «Типы событий»

1. Активируйте события:
   - **Входящее сообщение**
   - **Исходящее сообщение**
2. Сохраните настройки.

## 4. Настройка интеграции

1. На этом этапе вы уже должны были заполнить все важные поля.
2. Нажмите кнопку **"Сохранить"**.

## Проверка

1. Напишите сообщение в группу ВКонтакте от имени обычного пользователя.
2. В разделе **"Чаты"** появится новый элемент и отправленное сообщение.
3. Напишите ответное сообщение и он должно отправится в ВКонтакте от лица сообщества.
