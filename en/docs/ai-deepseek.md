# Connecting DeepSeek

This guide explains how to configure DeepSeek as an AI provider
for TG Support Bot.

You can select only one provider for the AI Assistant.

::: tip
Before proceeding, make sure the AI assistant is enabled by following
the [base integration guide](/en/docs/ai-integration).
:::

## Obtaining the API key

1. Register and sign in to the [DeepSeek Platform](https://platform.deepseek.com/).
2. Create a new API key in the key management section.
3. Copy the generated key — you will need it in the next step.

## Connecting the provider

Go to the **"AI Assistant"** section and click the **DeepSeek** card.

Fill in the form:
- Client ID
- Client Secret
- Provider Base URL
- Model
- Max response tokens
- Temperature
