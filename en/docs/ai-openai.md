# Connecting OpenAI

This guide explains how to configure OpenAI as an AI provider
for TG Support Bot.

You can select only one provider for the AI Assistant.

::: tip
Before proceeding, make sure the AI assistant is enabled by following
the [base integration guide](/en/docs/ai-integration).
:::

## Obtaining the API key

1. Sign in to [OpenAI API Keys](https://platform.openai.com/account/api-keys).
2. Create a new key and copy it — you will need it in the next step.

## Connecting the provider

Go to the **"AI Assistant"** section and click the **OpenAI** card.

Fill in the form:
- API Key
- Provider Base URL
- Model
- Max response tokens
- Temperature
